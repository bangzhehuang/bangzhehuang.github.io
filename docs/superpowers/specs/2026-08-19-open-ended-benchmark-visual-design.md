# Open-Ended Benchmark Homepage Visual

## Purpose

Create a full-canvas academic method figure showing how an open-ended physics
research task permits different valid trajectories while retaining one stable
physical ground truth.

## Composition

- Use a 16:9 white canvas filled edge to edge with a two-region method figure.
- Left region title: `Open-Ended Physics Task`.
- Enclose the left region with a thin dark border. Show a dashed system boundary,
  a split `Physics Simulator / Unknown Physical System` block, a `Research Agent`
  block, and orthogonal `actions` and `observations` arrows.
- Add the task statement `Task: identify the underlying physical structure`.
- Right region title: `+ Diverse Research Trajectories`.
- Begin with one `Initial Research State`, branch through three labeled paths
  (`SIMULATE`, `OBSERVE`, and `REFINE`), and converge them on one split target:
  `Physical Structure / Equivalent Observables`.
- Add the endpoint label `SHARED GROUND TRUTH` and the caption
  `Different trajectories. One stable target.`.

## Visual System

- Closely follow the supplied academic reference: Helvetica/Arial typography,
  heavy black section titles, dashed state boundaries, pale-yellow header cells,
  light-gray body cells, red primary arrows, and gray secondary arrows.
- Use black `#111111`, red `#C5161D`, medium gray `#646464`, light gray
  `#BFC0C2`, pale yellow `#FFF1C8`, and panel gray `#F1F1F1` on white.
- Use orthogonal or straight arrow segments, not decorative curves.
- Make labels large enough to survive the homepage thumbnail size.
- Avoid gradients, icon-only nodes, oversized circular symbols, software-style
  badges, decorative cards, and empty margins.

## Homepage Integration

- Publish the refined asset as `open-ended-benchmark-method.svg` and update the
  existing third-project image reference so browsers do not reuse the old visual.
- Visually inspect both the full figure and its rendered homepage card.
- No broad browser matrix is required.
